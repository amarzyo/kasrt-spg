# About This Project

This project is built using:

- Laravel 13
- Livewire
- Tailwind CSS
- FluxUI

Laravel is a web application framework with expressive, elegant syntax. Combined with Livewire and TailwindCSS, this stack provides a modern developer experience for building reactive and beautiful web applications without leaving PHP.

## Tech Stack

### Laravel 13
Modern PHP framework for building scalable web applications.

### Livewire
Full-stack framework for Laravel that makes building dynamic interfaces simple, without writing much JavaScript.

### Tailwind CSS
Utility-first CSS framework for rapidly building modern responsive interfaces.

### FluxUI
Beautiful UI components designed for Laravel + Livewire applications.

## Features

- Reactive UI with Livewire
- Modern responsive design using TailwindCSS
- Reusable UI components with FluxUI
- Authentication ready
- Clean and scalable project structure
- Fast development workflow
